# ✉️ Invite Card Management Tool

A lightweight, easily customizable tool to manage invitations via Firebase integration. It is designed with a simple structure, making it easily refactorable for a production environment and a custom domain.

**🔗 Live Demo:** [https://invite-card-theta.vercel.app/](https://invite-card-theta.vercel.app/)

## ✨ Features

- **Admin Dashboard:** Test the admin page with fixed credentials (easily configurable for production).
- **Visible Organization:** Clean overview of assigned members and invitation status.
- **Swappable Design:** The simple codebase structure allows for easy UI customizations and design changes.
- **Firebase Ready:** Built with Firebase integration in mind.

## ⚠️ Important Note for Local Testing

You can download the repository to test it locally and make design changes. However, **the database connection will not work out-of-the-box**. For security reasons, no Firebase API keys are included in this repository. To test backend features, you will need to provide your own Firebase configuration.
